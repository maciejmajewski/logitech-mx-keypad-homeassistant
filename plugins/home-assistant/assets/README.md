# Home Assistant logo

`ha-logomark-color.svg` and `ha-logomark-mono.svg` are the Home Assistant logomark from
https://github.com/home-assistant/assets (logo/home-assistant-logo.zip), unmodified.

They are **not** covered by this repository's MIT licence. The logo is a trademark of the
Open Home Foundation and the assets are released under CC BY-NC-SA 4.0
(https://creativecommons.org/licenses/by-nc-sa/4.0/): attribution required, no commercial
use, derivatives under the same licence. See NOTICE.md at the repository root.

`npm run icons` rasterises them (with `rsvg-convert`) into `package/metadata/Icon256x256.png`,
the static key icons and `src/logo.ts`.
